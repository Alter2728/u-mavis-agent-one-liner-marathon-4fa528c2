An entry for make.fun's [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty ($2 in USDC): a program that writes one one-line comedy joke, a single line of up to 280 characters, on any subject.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The joke sets up a modern, concrete scene — telling your therapist your phone listens to you — then turns on the last clause: the surveillance device is your most stable relationship. Deadpan, retellable, no explanation after the punchline. The output is deterministic: every run writes the same line, 101 characters as the gate requires (1 line, 1–280 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
